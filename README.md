# صِلة — منصة صلة الأرحام

منصة ويب (PWA) عربية تُعين المسلم على **معرفة أرحامه وصِلتهم**. تعمل على الجوال كتطبيق مثبَّت، وبدون إنترنت، والبيانات محفوظة على الجهاز فقط.

---

## التشغيل

### على الحاسب

```bash
npx --yes http-server "C:/Users/na900/Downloads/qu/silah" -p 5178 -c-1
```

ثم افتح `http://localhost:5178`.

> ملاحظة: فتح `index.html` بالنقر المزدوج يعمل، لكن ميزة العمل بدون إنترنت (Service Worker) تحتاج تشغيلها عبر خادم `http://` أو `https://`.

### النشر

المستودع يعمل على مسارين، والاختيار بينهما لا يحتاج أي تعديل في كود التطبيق:

| المستضيف | الإعداد | ملاحظات |
|---|---|---|
| **Railway** | يكتشف `railway.json` ويشغّل `node server.js` | خادم دائم — المسار المناسب إن كنت ستضيف قاعدة بيانات ومزامنة لاحقًا |
| **Cloudflare Pages** | أمر البناء فارغ · مجلد الإخراج `/` | استضافة ثابتة مجانية وموزّعة عالميًا؛ `server.js` يُتجاهل |

`server.js` خادم بلا اعتماديات: يضبط أنواع المحتوى ورؤوس الكاش (`sw.js` و`index.html` بلا كاش، الأيقونات سنة)، ويحجب ملفات المستودع غير الخاصة بالتطبيق، ويوفّر `/healthz` للفحص الصحي.

### على الجوال (تثبيتها كتطبيق)

1. ارفع المجلد على أي استضافة ثابتة (Netlify / Vercel / GitHub Pages / Cloudflare Pages) — لا يحتاج بناء ولا خادم خلفي.
2. افتح الرابط من متصفح الجوال.
3. **أندرويد (Chrome):** القائمة ← «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
   **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة وشاشة الترحيب |
| `styles.css` | التنسيقات (جوال أولًا، يدعم الوضع الليلي تلقائيًا) |
| `js/texts.js` | **⚠️ ملف المراجعة** — كل الآيات والأحاديث والأدعية مع التخريج |
| `js/relations.js` | نظام القرابة: درجات الرحم، الجهات، دورات الصلة |
| `js/store.js` | التخزين المحلي، حساب «حرارة الصلة»، الإحصاءات، النسخ الاحتياطي |
| `js/app.js` | الواجهة والتنقل |
| `sw.js` + `manifest.webmanifest` | العمل بدون إنترنت والتثبيت كتطبيق |

## المزايا المنفَّذة

**١) شجرة الأرحام** — ٣٤ صلة قرابة مصنَّفة من جهة الأب والأم والأصول والفروع، تُرتَّب تلقائيًا في خمس طبقات (الأجداد ← الوالدون والأعمام والأخوال ← جيلي ← الأبناء ← الأحفاد)، مع شريط يبيّن توزيع أرحامك بين الجهتين.

**٢) درجة الرحم** — تُحسب تلقائيًا:

| الدرجة | من تشمل | الدورة الافتراضية |
|---|---|---|
| رحم واجب الصلة | الوالدان، الأبناء، الإخوة، الأجداد | يوميًا – أسبوعيًا |
| رحم مؤكد | الأعمام، العمّات، الأخوال، الخالات، أبناء الإخوة | شهريًا |
| رحم موسّع | أبناء العم والعمّة والخال والخالة | كل ٣ أشهر |

الدورة قابلة للتعديل لكل شخص على حدة.

**٣) مؤشر حرارة الصلة** — لكل قريب حالة تُحسب من (الأيام منذ آخر تواصل ÷ الدورة المقترحة):

- 🟢 **موصول** — النسبة ≤ ٠٫٧٥
- 🟡 **قارب موعد الصلة** — النسبة ≤ ١٫٢٥
- 🔴 **يحتاج صلة** — تجاوز الدورة
- ⚪ **لم تُسجَّل صلة بعد**

**٤) شاشة اليوم** — تعرض ثلاثة أشياء فقط: من يستحق صلتك اليوم (١–٣ أسماء بحسب أولوية = التأخير × درجة الرحم)، ومناسبات قريبة، وآية أو حديثًا. الزر الأساسي `📞 اتصل الآن` يفتح الهاتف **ويُسجّل الصلة تلقائيًا**.

**٥) التسجيل بضغطة واحدة** — خمس أيقونات كبيرة: 🏠 زيارة · 📞 اتصال · 💬 رسالة · 🎁 هديّة · 🤲 دعاء.

> **قاعدة مقصودة:** الدعاء يُسجَّل كحسنة لكنه **لا يُصفِّر عدّاد التواصل** — الصلة تحتاج تواصلًا فعليًا. غيّرها من `resets` في `js/relations.js` إن أردت.

**٦) المناسبات** — ميلاد / زواج / ذكرى وفاة / مناسبة، سنوية مع تنبيه قبل الموعد.

**٧) النصوص الشرعية** — ١١ آية و١٣ حديثًا من الصحيحين و٥ أدعية قرآنية، كلها مع التخريج، وقابلة للمشاركة.

**٨) الإحصاءات** — عدد الصلات هذا الشهر، الأيام المتتالية، توزيع أنواع الصلة، ومن لم تُسجَّل معهم صلة بعد.

**٩) نسخة احتياطية** — تصدير/استيراد ملف `json` (استبدال أو دمج).

## النصوص الشرعية — للمراجعة قبل النشر

كل النصوص في ملف واحد: **`js/texts.js`**، وكل نص كائن مستقل بحقوله:

```js
{
  id: 'h-2',
  text: 'مَنْ سَرَّهُ أَنْ يُبْسَطَ لَهُ فِي رِزْقِهِ…',
  narrator: 'أنس بن مالك رضي الله عنه',
  source: 'أخرجه البخاري (٢٠٦٧) ومسلم (٢٥٥٧)',
  grade: 'متفق عليه',
  tag: 'ثمرات الصلة'
}
```

**السياسة المتبعة:** الأحاديث من **صحيح البخاري وصحيح مسلم فقط**، ولا يوجد في الملف حديث ضعيف ولا حسن ولا من كتب السنن.

- **لحذف نص:** احذف الكائن `{...}` كاملًا.
- **لإضافة نص:** انسخ نفس الشكل واملأ الحقول كلها.
- الأرقام: البخاري بترقيم فتح الباري، ومسلم بترقيم محمد فؤاد عبد الباقي.

## الخصوصية

- لا يوجد خادم، ولا حساب، ولا تتبُّع، ولا أي طلب شبكة خارجي.
- كل شيء في `localStorage` داخل متصفح الجهاز.
- **لذلك:** مسح بيانات المتصفح أو تغيير الجهاز يفقد البيانات — صدّر نسخة احتياطية بين حين وآخر.
